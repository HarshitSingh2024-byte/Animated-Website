# Sundown Studio — Animated Multi-Page Website

A visually rich, animated studio website built with vanilla HTML, CSS, and JavaScript. Features a cinematic loader, smooth scroll, hover-driven image previews, CSS blob animations, and a fully responsive layout — inspired by high-end creative agency websites.

---

---

## ✨ Features

- **Cinematic Loader** — Staggered text reveal animation on page entry
- **Locomotive Scroll** — Smooth inertia-based scrolling throughout
- **Animated Hero Blobs** — CSS keyframe-driven glowing orbs in the hero section
- **Marquee Text Strip** — Infinite horizontal scrolling text ticker
- **Hover Image Preview** — Fixed floating image appears on project list hover
- **Swiper.js Carousel** — Touch-friendly slide gallery on the work section
- **Fullscreen Menu Overlay** — Slide-down mobile menu with transition
- **Responsive Design** — Fully adapted for mobile (≤600px)
- **Custom Font Loading** — Neue Haas Display via `@font-face` (Light, Roman, Medium)
- **Multi-Page Structure** — Home, Work, Studio, Contact pages

## 🚀 Getting Started

No build tools or dependencies required. Just open locally:

```bash
git clone https://github.com/your-username/sundown-studio.git
cd sundown-studio
# Open index.html in your browser
```

Or deploy instantly to Netlify or Vercel by dragging the folder into their dashboard.
